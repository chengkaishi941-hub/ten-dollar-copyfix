# 短剧故事引擎：万事屋接单中

## 1. 已接受的戏剧承诺

- **来源**：creative-brief v0.1（方向 B）
- **焦点人物与追求**：陈野，要在 7 天内赚够 8000 元住院费，同时守住"不被拍到出手"。
- **昂贵阻力**：赵子骁（钱 / 程序 / 舆论 / 雇人）；雷振（录像 + 三场之约）。
- **反复回报**：每集一张订单完成 + 一次意外式打脸 + 关系进一格。
- **核心代价**：出手越多，暴露越多。
- **终止性转变**：EP9 陈野为 0 元订单公开出手。

## 2. 引擎回路

### 压力怎样启动
赵子骁针对林知夏出招 → 林知夏下单（或追加订单）→ 陈野必须在"赚钱 / 不暴露 / 守规矩"之间找出路。

### 主角惯常怎样应对
- 策略：**先谈价，再动手，动手伪装成意外**（绊倒、滑倒、门撞、球砸），或者用订单记录里的"黑料"走程序反制。
- 为什么有效：没人相信一个送外卖的能打；他比任何人都清楚校园里谁干过什么。
- 为什么同时制造新问题：意外太多就不像意外；翻订单记录会得罪更多人；每次都在留下视频或证人。

### 对抗力量怎样学习与反制
- 赵子骁：直接威胁（EP1）→ 收买（EP2）→ 程序封禁（EP2）→ 校外打手（EP4）→ 公开赌局（EP6）→ 与雷振结盟（EP7）→ 绑架夺 U 盘（EP8）。每次失败都换一种货币。
- 雷振：从不露面（EP5 电话）→ 请柬（EP7）→ 亲自下场（EP9）。

### 一轮冲突怎样留下下一轮压力

```text
触发：赵子骁出一招
→ 主角选择：接单 / 谈价 / 伪装出手
→ 反制：赵子骁换一种货币
→ 局部结果：订单完成，钱或名声有可见变化
→ 新代价/状态变化：暴露面扩大（视频、证人、被认出）
→ 下一股压力：更高层的对手注意到他
```

### 为什么人物不能轻易退出
奶奶的医药费；万事屋"接了不撤"的招牌（他唯一剩下的骄傲）；中段以后，他在乎林知夏。

## 6. 视觉、声音与制作方向

- **核心场域**：楼梯间、宿舍楼下外卖架、学生会办公室、奶茶店后厨、篮球场、地下拳场（仅 EP9）。
- **反复出现的物件/声音**：外卖保温箱（装奶茶也装"武器"）；万事屋接单提示音"叮——您有新的订单"；订单完成音效。
- **视觉气质**：日常戏明亮、饱和；打斗瞬间可短暂切成高对比、速度线（漫画感）；EP7–9 转冷色夜景。
- **明确不采用**：血腥特写、慢动作长打、画面内生成手机界面文字。

## 7. 引擎终止与变形

- 旧引擎（不能被拍到）终止于 EP9 公开出手。
- 新引擎（第二季）：零号回归，雷振背后的人找上门；陈野和林知夏以"万事屋"为名合伙接单。

## 8. 分集交接原则

- 每集兑现：一张订单的结果（钱 / 封禁 / 名声 / 关系）。
- 绝不能无原因重置：伤势、万事屋封禁状态、剩余天数、钱数、谁知道了什么。
- 允许的例外：EP7 录像的短闪回。
